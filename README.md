## 功能与使用方法

工作簿包含“使用说明”“客户清单”“跟进记录”三个工作表。客户清单预设 200 行，跟进记录预设 1000 行；客户来源、跟进阶段、跟进方式的预设单元格提供下拉选项，两张业务表配置筛选与标题冻结。

1. 客户清单每位客户维护一行，自行分配并核对客户编号。
2. 每次沟通在跟进记录新增一行，手动填写相同的客户编号。
3. 回到客户清单，更新阶段、最近跟进日期、下次跟进日期与下一步动作。
4. 按负责人、阶段或日期筛选，并自行保存和备份文件。

超出预设范围时需复制模板行，并扩展表格和数据验证范围。请先用示例版确认所用软件版本的显示和下拉效果。

## 使用限制

v1.0 需要手动填写、核对、更新与保存，不提供自动提醒、自动客户关联、多人权限、云端服务或 AI 分析。模板文件不含宏、公式或外部链接。筛选只改变显示范围，不提供权限隔离。客户资料的保存位置、备份、访问权限及合法使用由使用者管理。
